# stolibrindes — armazenamento do CMS

Este repositorio guarda o *delta* do catalogo do site Stoli (produtos editados, novos e ocultos) e as fotos enviadas pelo painel `/admin`.

- `catalogo-cms.json` — alteracoes feitas no painel.
- `uploads/` — fotos dos produtos novos/editados.

O catalogo base fica estatico no site. Mantenha este repositorio **publico** para as fotos carregarem.
